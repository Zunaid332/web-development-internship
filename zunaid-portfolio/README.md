# zunaid-portfolio

My personal portfolio, built with React and Vite.

The design is based on the "Web Developer Portfolio Website Template" from the Figma Community.

## Run it

You need Node.js 20 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Where things are

- Text, projects, skills and links: `src/data.js`
- Colors and styles: `src/index.css` (colors are at the top under `:root`)
- Each section: `src/components`
- Photo and CV: `public/`

## Build

```bash
npm run build
```

Upload the `dist` folder to Netlify, or connect the repo to Vercel.
